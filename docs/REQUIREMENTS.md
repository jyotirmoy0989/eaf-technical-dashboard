# Requirements

This independent project presents four in-page views: Full Dashboard, EAF Anatomy, Tap-to-Tap Cycle, and CO₂ & Technology Matrix. The executive KPI ribbon remains visible in all views. It contains a clickable six-part anatomy diagram, a six-stage illustrative process simulator, interactive emissions and production sliders, a decarbonization calculator, and a three-route technology comparison matrix.

The supplied `reference/electric_arc_furnace_interactive_dashboard.tsx` is the functional and engineering-content baseline. The dashboard is educational: its telemetry represents selected demonstration stages rather than live measurements. Responsive behavior, semantic controls, keyboard focus, reduced motion, and readable small-screen layouts are required.
