# Design

The interface follows the supplied functional reference: near-black and deep navy surfaces, slate technical panels, orange/amber heat accents, cyan/blue electrical accents, and green emissions metrics. Typography pairs clear system sans-serif headings with compact monospace labels and telemetry. The layout uses a persistent header, KPI ribbon, focused content cards, and a responsive horizontal table on narrow screens.

The Gemini visual reference URL was inaccessible through the available browser tool, so no additional visual details have been inferred from it. CSS includes visible keyboard focus and reduced-motion handling.
